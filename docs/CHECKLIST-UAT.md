# Checklist UAT e-Kinerja Versi 55

- [ ] Super User dapat login dan bukan pegawai.
- [ ] Hanya email pegawai aktif dengan akun aktif yang dapat login.
- [ ] Satu pengguna hanya memiliki satu sesi aktif.
- [ ] Pohon organisasi menjadi sumber jabatan, unit, atasan, dan akses default.
- [ ] Ketua melihat seluruh To-Do; Anggota hanya garis koordinasi.
- [ ] Sekretaris melihat seluruh lembaga; Kasubag melihat unit dan bawahan langsung.
- [ ] Staf dapat mengajukan To-Do dan Kasubag dapat menyetujui/menolak.
- [ ] PIC dapat memperbarui progress; verifikasi final berjalan.
- [ ] Absensi masuk/pulang mengikuti jam dan penutupan dinamis.
- [ ] Permintaan pembukaan absensi menuju atasan yang tepat.
- [ ] DL, Cuti, hari libur, rekap 21–20, dan format cetak sesuai aturan.
- [ ] Operator Absensi dapat mencetak seluruh pegawai tanpa akses lain berlebihan.
- [ ] Operator SAKIP dapat mengelola RKT/PK/Monev sesuai kewenangan.
- [ ] Agenda hanya dapat dikelola Kasubag/Editor sesuai unit.
- [ ] RKT, PK, anggaran, cascading, bukti dukung, dan periode monev berfungsi.
- [ ] Semua aksi penting menampilkan konfirmasi sebelum diproses.
- [ ] Audit log, rate limit, upload privat, backup, dan restore teruji.
- [ ] Tampilan desktop dan ponsel lulus pemeriksaan.
